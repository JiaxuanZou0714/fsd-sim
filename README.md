# FSD 城市自动驾驶模拟器

一个在浏览器中运行的自动驾驶演示，参考 Tesla FSD 的交互与可视化方式。车辆在 5×5 路口的城市路网中自主完成路线规划、车道保持、变道、红绿灯通行、跟车、礼让行人和绕行故障车辆。用户可以设置目的地、制造突发事件，或随时接管车辆手动驾驶。

## 运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev        # 开发服务器，默认 http://localhost:5173
npm run build      # 类型检查并构建到 dist/
npm test           # 无界面的仿真测试
```

地址后加 `#play` 可跳过开场说明，例如 `http://localhost:5173/#play`。

## 操作

| 按键 | 功能 |
| --- | --- |
| 点击小地图或路面 | 设置目的地 |
| `F` | 启用 / 退出 FSD |
| `W` `A` `S` `D` 或方向键，`空格` | 手动驾驶与制动；FSD 启用时按下即视为接管 |
| `R` | 随机目的地 |
| `J` | 在前方生成横穿马路的行人 |
| `B` | 在前方生成故障停驶车辆 |
| `C` | 切换视角（跟随、近距、俯视） |
| `T` | 模拟速度 1× / 2× / 4× |
| `P` | 暂停 |

右下角面板可调整车辆数量、行人数量、是否在到达后自动前往新目的地，以及是否随机触发突发事件。左下角统计 FSD 里程、接管次数、紧急制动次数和碰撞次数。

## 实现

仿真部分（`src/sim/`）不依赖 DOM，可在 Node 中直接运行测试；渲染部分（`src/render/`）使用 Three.js，界面部分（`src/ui/`）为原生 DOM。

| 模块 | 内容 |
| --- | --- |
| `world.ts` | 网格路网（每向两车道，右侧通行）、路口转向连接曲线、信号灯相位（直行、保护左转、行人专用相位） |
| `routing.ts` | 基于有向路段的 Dijkstra 路径规划，禁止掉头，左转和右转带附加代价 |
| `ego.ts` | 自车规划与控制：车道匹配定位、参考路径生成、车道选择与变道决策、IDM 纵向控制、Stanley 横向控制、运动学自行车模型 |
| `agents.ts` | 沿参考路径的障碍物扫描；对行人按自车到达各路径点的时间预测其位置 |
| `traffic.ts` | 其他车辆：沿车道行驶、随机选择转向、遵守信号灯、IDM 跟车、绕行停驶车辆、变道间隙检查 |
| `pedestrians.ts` | 行人：沿人行道行走，在行人相位通过人行横道；横穿马路的行人；被车辆阻挡时折返 |
| `simulation.ts` | 组合以上模块，处理突发事件、碰撞检测和统计 |

自车每一帧的决策顺序：

1. 将车辆位置投影到参考路径，进入新路段时重建路径。
2. 纵向约束取最小加速度：限速、弯道曲率限速、前方障碍物（IDM）、红灯或来不及通过的黄灯停止线、目的地停车点。
3. 转弯前需要的车道与当前车道不同时，或前方有停驶车辆时，检查目标车道前后间隙后发起变道；变道受阻 4 秒则返回原车道。
4. 横向控制使用车辆中心的 Stanley 控制器，加入路径曲率前馈。

## 测试

`tests/sim.test.ts` 覆盖以下场景：

- 任意两路段之间可规划出不含掉头的路线；目的地在同一路段后方时绕行街区。
- 多个随机种子下连续行驶 10 分钟，启用随机突发事件，无碰撞且多次到达目的地。
- 红灯前停在停止线处。
- 前方出现横穿行人时制动避让。
- 前方出现故障车辆时变道绕行。
- 手动接管计为一次接管。

## 局限

- 路网为规则网格，无高速、匝道和多车道路口。
- 其他车辆和行人由规则驱动，行为较为规整。
- 感知部分直接读取仿真中的真实位置，没有传感器噪声和识别误差。
